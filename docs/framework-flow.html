1. 한 줄 요약

화면은 React가 그리고, 개발/빌드는 Vite가 맡습니다. 코드는 GitHub에 올라가고, Vercel이 그 코드로 웹사이트를 만듭니다. 문서 내용과 사진은 브라우저가 Supabase에 직접 저장합니다.

Supabase 문서 DB + 사진 저장소

2. 각 도구가 하는 일

React 나무위키 스타일 UI. App.jsx가 헤더/본문/푸터를 붙이고, Article.jsx가 제목·프로필·목차·편집을 담당합니다.
Vite npm run dev로 로컬(http://localhost:5173)을 띄웁니다. 배포 시 npm run build로 정적 파일(dist/)을 만듭니다. VITE_로 시작하는 환경 변수만 브라우저 코드에 넣습니다.
GitHub 프로젝트 코드의 원본입니다. .env.local과 키는 올리지 않습니다. Vercel은 이 저장소를 보고 사이트를 빌드합니다.
Vercel GitHub 코드를 받아 Vite 빌드 후 CDN에 올립니다. 서버가 문서를 저장하지는 않습니다. 빌드 시 VITE_SUPABASE_URL, VITE_SUPABASE_ANON_KEY가 필요합니다.
Supabase Postgres 테이블 documents(id = main)에 제목·프로필·본문을 저장하고, Storage 버킷 photos에 이미지를 저장합니다.

3. 사람이 사이트를 볼 때

  1. 친구가 Vercel 주소로 접속합니다. Vercel은 이미 빌드된 React 파일을 내려줍니다.
  2. 브라우저에서 React가 켜지며 src/lib/supabase.js가 URL·anon 키로 클라이언트를 만듭니다.
  3. fetchDocument()가 documents에서 id=main 한 줄을 읽습니다.
  4. 제목, 이름/나이/종족/직군/웹사이트, 개요·상세·논란 및 사건사고·여담, 사진 URL이 화면에 그려집니다.

핵심: Vercel은 화면만 주고, 실제 글은 Supabase가 가지고 있습니다. 그래서 로컬과 배포 사이트가 같은 DB를 보면 내용이 같아집니다.

4. 글을 저장할 때

단락 [편집] 해당 목차(개요/상세/논란 및 사건사고/여담)만 텍스트 상자가 열립니다. 완료를 누르면 그 내용이 DB에 반영됩니다.
맨 위 편집 제목 + 프로필 칸 + 본문 전체를 한 번에 고칩니다. 완료 시 saveDocument()가 upsert 합니다.
  1. React가 입력값을 draft에 모읍니다.
  2. wikiApi.js가 Supabase REST로 documents를 업데이트합니다.
  3. 친구 브라우저가 새로고침하면 같은 줄을 다시 읽으므로 수정이 보입니다.

5. 사진을 올릴 때

  1. 프로필 사진 칸을 클릭하면 파일 선택창이 열립니다.
  2. 이미지가 Storage photos/main/시간.확장자로 업로드됩니다.
  3. 공개 URL을 받은 뒤 documents.photo_url, photo_path만 갱신합니다. 글 편집 중인 본문을 덮어쓰지는 않습니다.

4. 공개 URL 친구가 접속

로컬은 .env.local을 읽고, Vercel은 GitHub에 없는 그 파일을 모릅니다. 그래서 Settings → Environment Variables에 같은 키를 넣고 Redeploy해야 배포 사이트에서도 Supabase에 붙습니다. 변수를 넣은 뒤 새로고침만 하면 안 됩니다. Vite는 빌드하는 순간에 값을 JS 파일 안에 넣습니다.

7. 환경 변수

이름 VITE_SUPABASE_URL
의미 프로젝트 주소. 예: https://xxxx.supabase.co （/rest/v1/ 는 붙이지 않음）
이름 VITE_SUPABASE_ANON_KEY
의미 브라우저용 공개 키. 프론트에 들어가므로 RLS/GRANT로 권한을 제한합니다.

로컬: .env.local  /  배포: Vercel Environment Variables (Production)

8. 데이터가 쌓이는 곳

documents id, title, infobox(json), bodies(json), photo_url, photo_path, updated_at. 현재 문서는 id=main 한 줄입니다.
photos 버킷 프로필 이미지 파일. 공개 URL로 화면에 표시됩니다.

지금 구조는 로그인 없이 URL을 아는 사람이 읽고 쓸 수 있습니다. 친구들끼리 쓰는 용도입니다.

이 문서는 OnionWiki 현재 코드 기준입니다. 화면 프레임은 React, 빌드는 Vite, 코드 보관은 GitHub, 웹 배포는 Vercel, 문서/사진 저장은 Supabase입니다.
